# kalyannmey-data

Données publiques lues par [kalyannmey.fr](https://kalyannmey.fr).

- `simgaze.json` : chiffres iRacing Sports Car de Kalyann Mey (iRating, classements, départs, victoires), repris de [SimGaze](https://simgaze.com/leaderboard/pro-drivers/kalyann-mey/) avec l'accord de son propriétaire.
- Mise à jour automatique chaque lundi par `.github/workflows/simgaze.yml` (lancement manuel possible depuis l'onglet Actions).
